# Добрые слова при пожертвовании

- Необязательное поле формы `/donate/` привязывается к первому локальному платежу; при ежемесячных повторных списаниях текст не копируется.
- Текст длиной не более 500 символов хранится в `linka_donation_payments.donation_message` только после отдельного согласия; дата и версия согласия сохраняются рядом с ним. Текст не передаётся в YooKassa или fundraising outbox и отображается только администраторам WordPress на странице «Пожертвования».
- При штатном обезличивании просроченных платежей текст и свидетельство согласия очищаются вместе с данными жертвователя. Старые записи получают `NULL`; старый код с новой схемой продолжает работать.
- Публичный счётчик пожертвований скрыт; внутренняя синхронизация YooKassa и административная сумма остаются для сверки.
- PDF-согласие от 24.08.2026 перечисляет только имя, телефон и email. Для необязательного текста введена отдельная отметка согласия с ограниченной целью обработки; информация о сообщениях добавлена на HTML-страницу политики. PDF остаётся утверждённым исходным документом без изменений.
